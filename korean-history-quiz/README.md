# 한국사2 섹션별 개념 확인

배움책 개념 정리 문서의 `##` 섹션 20개를 기준으로 만든 400문제입니다.
각 섹션은 짧은 답 10문제와 OX 10문제로 구성되어 있습니다.

## 실행

이 브랜치를 내려받은 뒤 `index.html`을 Chrome, Edge, Safari 등 브라우저로 열면 됩니다.
별도 설치나 인터넷 연결이 필요하지 않습니다. GitHub의 파일 보기 화면에서는 실행되지 않으므로 파일을 내려받아 열어 주세요.

## 기능

- 섹션별 문제 선택 및 이전·다음 섹션 이동
- 자동 채점, 정답과 해설 확인
- 틀린 문제만 보기 및 섹션별 다시 풀기
- 해당 섹션의 원문 확인
- 브라우저 내 풀이 기록 저장과 모바일 화면 지원

짧은 답은 등록된 정답 표현을 기준으로 채점하며, 띄어쓰기와 문장부호는 무시합니다.
브라우저의 로컬 저장소가 제한된 경우 페이지를 닫으면 기록이 유지되지 않을 수 있습니다.

## 확인한 동작

20개 섹션·400문항 구성, 전체 정답 채점, 오답·미응답 처리, 다시 풀기, 기록 복원,
모바일 화면, 로컬 저장소 사용이 차단된 경우의 문제 풀이를 브라우저에서 확인했습니다.
