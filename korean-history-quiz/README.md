# 한국사2 섹션별 개념 확인

배움책 개념 정리 문서의 `##` 섹션 20개를 기준으로 만든 **1,200문제**입니다.
각 섹션은 **3회차 × 회차당 20문제 = 60문제**로 구성되어 있습니다.

| 회차 | 구성 | 학습 내용 |
| --- | --- | --- |
| 1회차 | 짧은 답 10 + OX 10 | 기존 문제로 기본 개념 확인 |
| 2회차 | 4지선다 20 | 설명을 읽고 인물·사건·제도의 관련 항목 선택 |
| 3회차 | 빈칸 채우기 20 | 관련 개념의 핵심 용어·인물·연도를 직접 입력 |

2·3회차는 같은 원문 내용을 개념 연결과 핵심 내용 회상이라는 서로 다른 질문으로 복습합니다.

## 실행

이 브랜치를 내려받은 뒤 `index.html`을 Chrome, Edge, Safari 등 브라우저로 열면 됩니다.
별도 설치나 인터넷 연결이 필요하지 않습니다. GitHub의 파일 보기 화면에서는 실행되지 않으므로 파일을 내려받아 열어 주세요.

## 기능

- 섹션별 1·2·3회차 선택, 회차별 진행 상태와 점수 표시
- 이전·다음 회차 및 섹션 이동
- 자동 채점, 정답과 해설 확인
- 틀린 문제만 보기 및 회차별 다시 풀기 (다른 회차의 답안 유지)
- 해당 섹션의 원문 확인
- 회차별 브라우저 내 풀이 기록 저장과 모바일 화면 지원
- 같은 브라우저·같은 파일 주소에서 기존 400문제 버전의 기록을 1회차로 자동 이전

짧은 답은 등록된 정답 표현을 기준으로 채점하며, 띄어쓰기와 문장부호는 무시합니다.
브라우저의 로컬 저장소가 제한된 경우 페이지를 닫으면 기록이 유지되지 않을 수 있습니다.

## 확인한 동작

20개 섹션 × 3회차 × 20문항 구성, 전체 정답 채점, 오답·미응답 처리, 회차 간 기록 분리,
회차별 다시 풀기, 기존 기록 이전, 새로고침 후 복원, 모바일 화면,
로컬 저장소 사용이 차단되거나 저장 기록이 손상된 경우를 확인했습니다.

## 내용 수정 및 HTML 재생성

배포·실행에는 `index.html` 한 파일만 필요합니다. 아래 소스는 내용과 UI를 수정할 때 사용합니다.

- `src/round1.json`: 1회차 문제와 섹션별 원문
- `src/extra-facts.txt`: 2·3회차의 개념 연결 및 빈칸 문제 원본. 각 줄은 `항목|설명 [정답/허용 답안]` 형식
- `src/app.js`, `src/style.css`, `src/shell.html`: 화면과 동작
- `build.py`: 문항 수·보기·중복 검증 후 단일 HTML 생성 (Python 표준 라이브러리만 사용)

저장소 루트에서 실행:

```sh
python korean-history-quiz/build.py
```
